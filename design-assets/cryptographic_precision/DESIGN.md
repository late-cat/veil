## Brand & Style

This design system embodies high-assurance privacy, institutional trust, and sovereign data ownership. Built for elite enterprise research, confidential internal feedback, and whistleblower channels, the aesthetic bridges the frictionless ergonomics of high-tier productivity tools (Linear, Notion) with the uncompromising visual authority and technical rigor of developer infrastructure (Vercel, Stripe).

### Visual Aesthetic & Style Direction
- **Minimalist Modernism with Tactile Cryptographic Subtlety**: A pristine light-mode atmosphere relying on micro-textures, precise structural outlines, and optical balance rather than decorative noise.
- **Atmosphere of Provable Integrity**: Interacting with the system feels mathematically verified. Statuses, verification keys, and zero-knowledge receipts are treated as first-class architectural elements rather than technical afterthoughts.
- **Focus & Serenity**: Canvas-like layout execution allows distraction-free survey composition and respondent completion, evoking the calm clarity of high-end editorial tools.

## Colors

The palette establishes an immediate sensation of clinical precision and mathematical certainty through a light, luminous base tempered by deep slate structure and vibrant emerald-teal verification accents.

### Palette Architecture
- **Primary (`#0D9488` / Teal-600)**: The core cryptographic signature. Applied to confirmed ZK-verifications, active progress indicators, primary interactive states, and trusted proof seals.
- **Secondary (`#0F172A` / Slate-900)**: Deep mineral black used for primary actions requiring executive weight, crisp display typography, and framing high-contrast anchors.
- **Tertiary (`#14B8A6` / Teal-500)**: Lighter luminous teal utilized for micro-accents, data-viz gradients, and interactive hover rings.
- **Surface Canvas (`#FAFAFA` transitioning to `#F5F5F7`)**: Warm architectural off-white that eliminates screen glare while providing subtle separation against pure white cards (`#FFFFFF`).
- **Borders & Separators (`#E2E8F0` and `#EAECF0`)**: Low-contrast boundaries that preserve spatial relationships without producing visual clutter.
- **Functional States**:
  - **Verified / Sealed**: `#0D9488` (Teal) with subtle 10% tint fills (`#F0FDFA`).
  - **Encrypted / Pending**: `#6366F1` (Indigo-500) for mathematical handshakes and active computing states.
  - **Tamper Alert / Revoked**: `#E11D48` (Rose-600) with `#FFF1F2` backgrounds.

## Typography

The typographical engine operates on a three-tier hierarchy:
1. **Outfit (Headlines & Display)**: Provides architectural authority, circular geometric clarity, and an elevated tech-forward tone.
2. **Inter (Body & Functional Text)**: Delivers peerless legibility at micro and macro scales, neutral neutrality, and robust structural flow for complex survey prompts.
3. **JetBrains Mono (Technical & Cryptographic Context)**: Reserved strictly for hashes, cryptographic signatures, Zero-Knowledge proof roots, keys, and tabular metadata.

### Typographic Rules
- Never use JetBrains Mono for continuous conversational copy; it is strictly an informational proof badge or data artifact indicator.
- Maintain tight negative tracking on Outfit headings (`-0.02em` to `-0.03em`) to replicate the compressed, intentional look of top-tier SaaS landing pages and dashboards.
- Numbers within tables and metrics must always render with tabular figures (`font-feature-settings: 'tnum' 1`).

## Layout & Spacing

This design system uses a combined spatial model based on an 8-point base grid:
- **Distraction-Free Flow (Respondent Canvas)**: Single-column centered container constrained strictly to `44rem` (704px). Content breathes with generous vertical padding, prioritizing focus, zero cognitive friction, and rapid keyboard navigation.
- **Enterprise Verification Deck (Dashboard/Admin)**: A 12-column dynamic grid restricted to a max width of `76rem` (1216px) with dynamic `gutter-desktop` (2rem) and balanced side gutters.

### Breakpoint Matrix
- **Mobile (< 640px)**: Single column reflow, persistent bottom-sheet controls for survey actions, edge gutters of `1rem`.
- **Tablet (640px – 1024px)**: 6-column operational grid, collapsing cryptographic detail sidebars into collapsible drawer surfaces.
- **Desktop (> 1024px)**: Standard 12-column analytical layout with persistent verifiable side-panels.

## Elevation & Depth

Visual depth is achieved through ambient light diffusion, subtle boundary delineation, and layered white surfaces rather than dark, heavy drop shadows.

### Elevation Hierarchy
1. **Flat Base Canvas (`#FAFAFA`)**: The bottom plane. Unaltered, matte, structural ground.
2. **Elevated Cards (`#FFFFFF`)**:
   - Outlined with a hairline border (`1px solid #EAECF0`).
   - Grounded with an ambient, multi-layered diffuse shadow: `0 1px 2px rgba(15, 23, 42, 0.03), 0 4px 12px rgba(15, 23, 42, 0.04)`.
3. **Floating Controls & Modals**:
   - Backed by an ultra-soft optical shadow: `0 8px 30px rgba(15, 23, 42, 0.06), 0 1px 3px rgba(15, 23, 42, 0.04)`.
   - Surrounded by an inner border highlight (`inset 0 1px 0 rgba(255, 255, 255, 0.8)`).
4. **Verifiable Glass Sheets**:
   - `backdrop-filter: blur(12px) saturate(180%)`.
   - Semi-translucent surface: `rgba(255, 255, 255, 0.82)`.
   - Outlined with subtle chromatic teal diffusion: `1px solid rgba(13, 148, 136, 0.12)`.

## Shapes

The shape system leverages calculated modern rounding (`roundedness: 2` — `0.5rem` / 8px base, scaling up to `1rem` / 16px for primary containers). This achieves an approachable, modern feel while preserving structural, technical rigor.

### Geometry Specifications
- **Micro UI (Badges, Monospace proof chips)**: `0.375rem` (6px) for compact, machine-rendered aesthetics.
- **Interactive Inputs, Dropdowns, Segmented Tabs**: `0.5rem` (8px).
- **Surface Cards, Verifiable Proof Modules**: `0.75rem` to `1rem` (12px to 16px).
- **Survey Response Option Tiles**: `0.625rem` (10px) with distinct outer hairline focus rings.
- **Action Pills & Shield Badges**: Full pill shape (`9999px`) reserved exclusively for security state indicators, verifiable signatures, and step navigation tags.

## Components

### Buttons
- **Primary Executable**: Deep charcoal fill (`#0F172A`), crisp white text, micro-inset top glow (`inset 0 1px 0 rgba(255, 255, 255, 0.15)`), active scale feedback (`scale(0.98)`).
- **Cryptographic Trust Action**: Rich emerald/teal fill (`#0D9488`), pure white typography, subtle teal ambient glow on hover (`0 0 16px rgba(13, 148, 136, 0.25)`).
- **Secondary / Ghost**: Pure white background, `1px solid #E2E8F0`, slate-700 typography (`#334155`), hover fill `#F8FAFC`.

### Zero-Knowledge Shield Badges
- Pill-shaped container (`border-radius: 9999px`).
- Background: Soft mint tint (`#F0FDFA`), border: `1px solid #CCFBF1`.
- Content: Micro shield icon, monospace cryptographic ID (e.g., `ZK:0x8f2a...c89`), and live pulse dot (`#0D9488`).

### Survey Response Cards (Distraction-Free)
- Surface: `#FFFFFF`, border: `1px solid #E2E8F0`.
- Left-aligned indicator: Monospaced keyboard shortcut cue (e.g., `[A]`, `[1]`) in light slate pill.
- Hover State: Border transition to `#0D9488` (Teal-600) with a 2px offset micro-ring (`rgba(13, 148, 136, 0.08)`).
- Selected State: Background `#F0FDFA`, border `#0D9488`, checkbox/radio marked with solid teal fill and pure white check icon.

### Verifiable Tally & Results Cards
- Surface: `#FFFFFF` card with hairline `#EAECF0` border.
- Header contains title, total verifiable count, and an "Audit Proof" button triggering an inline drawer revealing the cryptographic Merkle path.
- Progress bars use smooth teal-to-emerald gradient fills (`linear-gradient(90deg, #0D9488 0%, #14B8A6 100%)`) with tabular monospace percentage counts.

### Form Inputs & Textareas
- Background `#FAFAFA`, resting border `#E2E8F0`.
- Focus State: Background `#FFFFFF`, border `#0D9488`, outer glow `0 0 0 3px rgba(13, 148, 136, 0.15)`.
- Input placeholder in muted slate (`#94A3B8`), input value in slate-900 (`#0F172A`).
